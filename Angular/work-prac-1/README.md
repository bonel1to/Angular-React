# Angular - Практика 1

Учебный проект с примерами компонентов, сервисов и списков.

В приложении есть счётчики, список покупок, список задач с фильтрами и избранным, а также корзина товаров. Задачи сохраняются после перезагрузки страницы.

## Запуск

```bash
cd Angular/work-prac-1
npm install
npm start
```

Открой [http://localhost:4200](http://localhost:4200).

Для сборки проекта:

```bash
npm run build
```
