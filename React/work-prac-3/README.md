# Рабочая практика 3

Приложение «Мои задачи» на React. Задачи сохраняются в `localStorage`, список можно фильтровать и открывать подробности каждой задачи.

## Запуск

Из корня репозитория выполните:

```bash
cd work-prac-3
npm install
npm run dev
```

Откройте адрес, который Vite покажет в терминале.
