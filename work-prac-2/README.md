# Рабочая практика 2

В этом React-проекте находится Todo-приложение: добавление, редактирование, выполнение и удаление задач, приоритеты, фильтры, поиск и сортировка.

Запуск из корня репозитория:

```bash
cd work-prac-2
npm install
npm run dev
```

Адрес будет тот, который Vite покажет в терминале.
